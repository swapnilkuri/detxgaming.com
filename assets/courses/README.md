# Course thumbnails

Upload your course thumbnail images into this folder with these EXACT filenames
(case-sensitive, including spaces, parentheses, and the .png extension).
The site is already wired to look for these files here — no code changes needed
once you add them.

- How to Start YouTube Journey.png
- YouTube SEO for Gaming (ChatGPT + VidIQ style).png
- Learn Instagram Algorithm (Gaming Reels).png
- How to Start Professional Live Stream (Streamlabs).png
- CapCut Editing for Gaming (ShortsReels).png

- Professional Thumbnail using Canva + AI (Gemini style).png

Until a file is uploaded, that course's card will show a
"Thumbnail coming soon" placeholder instead of a broken image icon.

Recommended size: 1280x720 (16:9), keep each file under ~500KB for fast loading.
